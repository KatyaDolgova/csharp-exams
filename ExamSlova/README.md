# ExamSlova

Windows Forms приложение на C# для поиска запрещённых слов в файлах. Рекурсивно обходит выбранную папку (или весь диск), ищет в текстовых файлах заданные слова, заменяет их на `*******`, сохраняет изменённую копию и формирует отчёт.

## Возможности

- **Выбор места поиска** - дерево всех дисков и папок компьютера.
- **Список запрещённых слов** - вводится вручную или загружается из `.txt`-файла (по одному слову на строку).
- **Поиск с управлением** - старт, пауза, возобновление, отмена; обход параллелен по ядрам процессора (`Parallel.ForEach`).
- **Обработка находок**: совпадения в тексте заменяются звёздочками, изменённая копия файла сохраняется в подпапку `newFiles`, оригинал файла с совпадением тоже копируется туда же.
- **Отчёт** `report_<дата>.txt` со списком найденных файлов и топ-10 самых частых слов.
- **Просмотр результатов**: таблица всех находок и отдельное окно топ-10 слов.
- **Режим командной строки**: `ExamSlova.exe <путь_к_папке>` запускает поиск без интерфейса и закрывается по завершении.
- **Один экземпляр приложения** - повторный запуск показывает предупреждение вместо второго окна.

## Технологии

- C#, Windows Forms, .NET Framework 4.7.2
- `Task`, `Parallel.ForEach`, `CancellationToken`, `ConcurrentBag<T>`

## Запуск

1. Откройте [ExamSlova.sln](ExamSlova.sln) в Visual Studio.
2. Соберите и запустите (F5).
3. На главном окне выберите папку для поиска в дереве, задайте список запрещённых слов и папку для сохранения результатов, нажмите «Начать поиск».

Результаты (отчёт и изменённые копии файлов) сохраняются в указанной вами папке, в подпапке `newFiles`.
