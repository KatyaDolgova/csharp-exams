# ToDoList

Веб-приложение на ASP.NET Core 8 (Razor Pages) - простой список дел. Без базы данных: список хранится в памяти процесса.

## Возможности

- Добавление задачи.
- Отметка «выполнено» / «не выполнено».
- Редактирование названия задачи в модальном окне.
- Удаление задачи с подтверждением; выбор «больше не спрашивать» запоминается в `localStorage` браузера.

## Технологии

- ASP.NET Core 8, Razor Pages
- Bootstrap, jQuery (подключены локально из `wwwroot/lib`, без CDN)

## Запуск

1. Откройте [ToDoList.sln](ToDoList.sln) в Visual Studio (или выполните `dotnet run` в папке `ToDoList/` при установленном .NET 8 SDK).
2. Запустите (F5 / `dotnet run`) - откроется страница со списком дел.

## Ограничения

- Данные хранятся только в памяти (`Singleton`-сервис `ToDoService`): список сбрасывается при перезапуске приложения.
- Это учебный проект без базы данных и без многопользовательского разделения - все, кто открыл сайт, видят один общий список.
