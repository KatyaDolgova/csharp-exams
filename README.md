# OlimpiadaExam

Windows Forms приложение на C# для учёта Олимпийских игр. Позволяет вести справочники олимпиад, видов спорта, соревнований, участников и результатов, а также строить отчёты по медалям и спортсменам.

## Возможности

**Редактирование данных (CRUD)** через меню главной формы:
- олимпиады;
- виды спорта;
- соревнования;
- участники (с фото);
- результаты (место и медаль);
- просмотр всех данных.

**Отчёты (LINQ)** на главной форме:
- медали по странам на выбранной олимпиаде (золото, серебро, бронза);
- медалисты олимпиады по видам спорта;
- страна с наибольшим числом золотых медалей;
- спортсмен с наибольшим числом золота в выбранном виде спорта;
- страна, чаще всех принимавшая Олимпиаду;
- олимпийская сборная страны (ФИО и дата рождения);
- статистика выступлений страны на олимпиаде.

## Технологии

- C#, Windows Forms, .NET Framework
- Entity Framework 5 (Database First, модель `ExamOlimp.edmx`)
- SQL Server LocalDB (`ExamOlimpBd.mdf`)

## Структура базы данных

| Таблица | Назначение |
|---|---|
| `Olympus` | олимпиады: год, тип, страна, город |
| `TypesOfSports` | виды спорта |
| `Competitions` | соревнования: олимпиада, вид спорта, число участников |
| `Participants` | спортсмены: ФИО, страна, вид спорта, дата рождения, фото |
| `Results` | результаты: участник, олимпиада, место, медаль |

## Запуск

1. Откройте `OlimpiadaExam.sln` в Visual Studio.
2. Восстановите NuGet-пакеты (Visual Studio сделает это при сборке).
3. Убедитесь, что установлен SQL Server LocalDB.
4. Нажмите F5.

Файл БД `OlimpiadaExam/ExamOlimpBd.mdf` уже содержится в репозитории. Чтобы заполнить пустую базу тестовыми данными, выполните по порядку:

1. `ExamOl.sql` - олимпиады;
2. `ExamSql.sql` - виды спорта, соревнования, участники, результаты.
