# ExamMonitoring

Windows Forms приложение на C# для контроля за компьютером (прокторинг). Отслеживает нажатия клавиш, переключение окон и запуск программ, а при нарушении правил формирует отчёт и может завершить запрещённый процесс.

⚠️ **Это учебный проект.** Он использует глобальный перехват клавиатуры (по сути, кейлоггер) и слежение за запущенными процессами. Запускайте его только на своём компьютере или с явного согласия того, за чьим компьютером наблюдаете.

## Возможности

- **Перехват клавиатуры** через низкоуровневый хук `WH_KEYBOARD_LL`: опционально пишет каждое нажатие в `logs/keystrokes.txt`.
- **Модерация по запрещённым словам**: если в последних 50 нажатиях встречается слово из списка, создаётся отчёт `violation_*.txt`.
- **Слежение за активным окном** через `SetWinEventHook`: имя запущенной программы пишется в `logs/processes.txt`.
- **Блокировка запрещённых программ**: фоновая задача каждые 5 секунд закрывает процессы из чёрного списка и создаёт отчёт `banned_app_*.txt`.
- **Просмотр отчётов** во встроенном окне: нажатия клавиш, запуски процессов, нарушения.

## Технологии

- C#, Windows Forms, .NET Framework 4.7.2
- Win32 API через P/Invoke (хуки клавиатуры и окон)

## Запуск

1. Откройте `ExamMonitoring.sln` в Visual Studio и соберите проект.
2. Скопируйте [settings.example.txt](settings.example.txt) в `settings.txt` в папку с собранным `.exe` (`bin/Debug` или `bin/Release`) и настройте под себя.
3. Запустите приложение, откройте «Настройки», при необходимости поправьте значения - они сохранятся в `settings.txt`.
4. Нажмите «Начать мониторинг».

Логи и отчёты сохраняются в папке, указанной в `LogFilePath` (по умолчанию `logs`), рядом с `.exe`.

## Формат settings.txt

```
LogKeyStrokes=False
ModerationEnabled=False
LogFilePath=logs
ForbiddenWords=слово1,слово2
BannedProcesses=chrome.exe,discord.exe
```
